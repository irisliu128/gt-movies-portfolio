GT Movies Store

GT Movies Store is a Django application split into four apps — home, movies, cart and accounts — each owning its own models, URLs and templates. Movies carry a name, price, description and cover image. Visitors register, browse and search the catalog, leave reviews only they can edit or delete, build a cart held in the session, and check out into a permanent order record. Every view hands its template a single template_data dictionary, so the view-to-template contract is identical across all four apps.
